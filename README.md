# Footprint Studio website

Marketing site for Footprint Studio: services, case studies, pricing, about, blog, FAQ and a free-audit contact form.

It's a single static file (`index.html`) with no build step. Fonts load from Google Fonts.

## Run locally

Open `index.html` in a browser.

## Deploy with GitHub Pages

1. Go to **Settings → Pages**, set **Source** to "Deploy from a branch", choose `main` and `/ (root)`, then save.
2. The site will be live at `https://wuemilyy-stack.github.io/footprint-studio/` within a minute or two.

## Before launch

- [ ] Replace the sample case studies and placeholder client quote
- [ ] Confirm prices in the Pricing section
- [ ] Replace the placeholder email and phone in the Contact section
- [ ] Connect the contact form to a backend (e.g. Formspree, Netlify Forms, or your CRM) and remove the "Preview site" note
- [ ] Write the blog posts or link the cards to real articles
